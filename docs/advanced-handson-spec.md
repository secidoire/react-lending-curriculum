# 発展編ハンズオン仕様

## 出発点
- 0-3のsolution（`mini-react.js`）をコピーして `handson/advanced/mini-react-plus/` に置く。
- 0-3はDOM要素（文字列のtype）しか扱っていない。発展編では関数コンポーネントを扱えるように拡張する。

## 本物との違いを明記する簡略化（READMEとコード冒頭に書く）
- Fiberもどきは木構造ではなく、「木の中の位置（親のパス＋key、keyがなければindex）」をキーにしたMapで保持してよい。
- 中断・優先度・並行レンダリングは実装しない（説明だけ）。
- 差分更新は0-3の範囲のまま（移動の最適化はしない）。

## ステップ
各ステップは README（お題）/ starter / solution / tests を持つ。starterは前ステップのsolution。

### 01 Fiberもどき（A-1）
- typeが関数なら呼び出し、戻り値を再帰的に処理する。
- 位置をキーにしたインスタンスMapを作り、各インスタンスに `{ hooks: [], hookIndex: 0 }` を持たせる。
- テスト：同じ位置の同じコンポーネントは同じインスタンスを再利用する。typeが変わると新しいインスタンスになる。

### 02 useState（A-1）
- グローバルな `currentInstance` を、コンポーネント呼び出しの直前に設定する。
- `useState(initial)` は `currentInstance.hooks[hookIndex++]` を読み書きする。
- テスト：2つのuseStateが独立して値を保持する。再レンダリングしても値が消えない。

### 03 順番のルールを壊す（A-1、体験用）
- お題：if文の中でuseStateを呼ぶコンポーネントを書き、条件を切り替えて値がずれることを確かめる。
- 実装はしない。READMEで「なぜずれたか」をhooks配列の図で説明させる。
- テスト：ずれが起きることを確認するテスト（教材用に、壊れた挙動そのものを表明する）。

### 04 トリガーとバッチング（A-1）
- setStateはその場で描き直さず、更新をキューに積んで `queueMicrotask` で1回だけ描き直しを予約する。
- 関数型更新 `setX(prev => ...)` に対応する。キューを順に適用する。
- テスト：同じハンドラ内で3回setStateしても描画は1回。`setX(x + 1)` ×3 は+1、`setX(p => p + 1)` ×3 は+3。

### 05 Object.isによる省略（A-1）
- 適用後の値が `Object.is` で前と同じなら、描き直しを予約しない。
- お題：`push` してから同じ配列をsetStateし、画面が変わらないことを確かめる。スプレッドに直して変わることを確かめる。
- テスト：同じ値のsetStateでは描画回数が増えない。

### 06 レンダーとコミットの分離（A-2）
- 「新しい仮想ノード木を作る（レンダー）」と「patchでDOMに反映する（コミット）」を関数として分ける。
- コミット中のDOM操作を `commitLog` に記録する（例：`setText`、`setAttr`、`insert`、`remove`）。
- お題：値の変わらないsetState以外の再レンダリング（例：親だけが変わる）で、子のレンダーは走るがcommitLogは空になるケースを作る。
- テスト：再レンダリングが起きても、変化がなければcommitLogが空である。

### 07 useEffect（A-2）
- コミット後に、依存配列を前回と `Object.is` で要素ごとに比べ、変わったものだけ実行する。クリーンアップを先に呼ぶ。
- 実行タイミングは `setTimeout(0)` で描画後を模す（本物とタイミングの実装が違うことをREADMEに明記する）。
- お題：依存配列にオブジェクトリテラルを入れて、毎回実行されることを確かめる。
- テスト：依存配列が変わらなければ実行されない。変わったらクリーンアップ → 実行の順で呼ばれる。

### 08 memoもどきと構造共有（A-2、時間があれば）
- `memo(Component)` を実装する。前回のpropsと各propを `Object.is` で浅く比較し、同じならレンダーをスキップする。
- お題：正規化したデータ（itemsById・loansById）で1件だけ更新し、変更していない側の子がスキップされることを確かめる。`onClick={() => ...}` を渡すとスキップされなくなることも確かめる。
- テスト：参照が同じpropsならレンダー回数が増えない。

## 規模の目安
- solution全体で `mini-react-plus.js` は400行以内。
- 各ステップのお題は15〜20分で終わる分量にする（A-1：01〜05、A-2：06〜08＋デモ）。

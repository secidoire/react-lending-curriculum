# 視覚デモ仕様（3本のみ）

## 共通制約
- `demos/<名前>/index.html`をfile://で直接開いて動くこと。スライドには`<iframe data-src>`で埋め込む。
- (a)は素のJSで作る。(b)(c)はReactをViteでIIFE形式の単一スクリプトにビルドし、`demos/dist/`にコミットする（React 19にはUMDがなく、file://では`type="module"`がブロックされる場合があるため）。
- 本文は18px以上、ボタンは最大4つ、画面上の説明は1行、コードは300行以内。ハイライトは0.6秒のフェードだけにし、枠線とラベルを付ける。

## (a) 全描き直し vs 差分更新
- **見せること**：全描き直しだと全ノードが置き換わり、フォーカスが消える。差分更新だと変わったノードだけが更新され、フォーカスが残る。
- **画面**：左右2ペイン。それぞれに貸出一覧（5行、各行にメモ入力欄）と、DOM変更カウンタ（追加・削除・属性・テキスト）。
- **操作**：[1件追加] [1行目のステータス切替] [自動入力] [リセット]。
- **実装**：0-3のsolutionを縮小コピーして同梱する。MutationObserverで変更ノードを検知してハイライトとカウントを行い、`document.activeElement`を「フォーカス：なし／メモ欄3」のように表示する。

## (b) keyの有無とリスト並べ替え
- **見せること**：非制御の入力欄では、key=indexやkeyなしだと、追加・並べ替えのときに入力内容が別の行にずれる。
- **画面**：3列（keyなし／key=index／key=id）。各列に備品名と「借りる理由」欄（defaultValue）を4行並べ、keyの値も表示する。
- **操作**：[先頭に追加] [逆順] [シャッフル] [リセット]。最初に「理由A〜D」を自動で入力しておく。
- **実装**：React 19.3。名前と理由が一致しない行に「ずれ」ラベルを付ける。Preserving and Resetting Stateの「同じ位置・同じ型ならstateが保持される」と結びつける。

## (c) クロージャによる古い値のキャプチャ
- **見せること**：依存配列を`[]`にした`setInterval(() => setCount(count + 1))`が1で止まる理由を、レンダーごとのスナップショットとして見せる。
- **画面**：左にカウンタと現在のコード、右に「レンダー履歴」のカード（#1 count=0、#2 count=1…）。コールバックが参照しているカードを矢印で示す。
- **操作**：4つのモードを切り替える [バグ版] [関数型更新] [依存配列にcount] [useEffectEvent版]。
- **実装**：レンダーごとにrenderIdとcountをrefの履歴に積む。依存配列モードでは、intervalの作り直しを「×→新規」と表示する。
- **メッセージ**：stale closureはReactのバグではなく、JSのクロージャの性質。3つの対策はそれぞれ意味が違う。

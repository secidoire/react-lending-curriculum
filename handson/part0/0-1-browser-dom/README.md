# 0-1 ブラウザとDOM

## 状況

総務の田中さんから、貸出一覧のページについて相談が来ました。

> 「貸出一覧のページを右クリックして『ページのソースを表示』で見たHTMLと、検証ツールで見えるHTMLが違うんです。どっちが本物ですか？
> それと、検証ツールで『佐藤』を『佐藤（総務）』に直したのに、リロードしたら元に戻っていました。保存されないんですか？」

もう1件、開発チームの先輩からも。

> 「備品が1000件になったら一覧の表示が遅くなりそう、という話が出てる。DOMを触るのは遅いって聞くけど、本当に遅いのはどこなのか、測って教えてほしい。」

今日はコードをほとんど書きません。ブラウザの中で何が起きているかを、自分の目で観察します。

## 準備

リポジトリのルートで次を実行し、表示されたURLをChrome（またはEdge）で開きます。

```bash
npx vite handson/part0/0-1-browser-dom/starter
```

観察したことは `handson/part0/0-1-browser-dom/starter/notes.md` に書き込みます。

## やること

### 1. 「ページのソースを表示」と Elements パネルを見比べる
- ページを右クリック →「ページのソースを表示」で開いたタブと、DevTools（田中さんの言う「検証ツール」。F12で開く）の Elements パネルを並べます。
- 違っているところを3つ以上見つけて、`notes.md` に書きます。

### 2. Elements パネルで書き換えて、リロードする
- Elements パネルで「佐藤」をダブルクリックして「佐藤（総務）」に書き換えます。
- 画面が変わったことを確かめてから、リロードします。
- エディタで `starter/index.html` を開き、中身がどうなっているかを確かめます。
- 別の文字（ほかの人の名前や、状態）でも、「書き換える → リロードする → `index.html` を確かめる」をあと2回くり返します。

### 3. Console から文字を変更する
- Console パネルにJavaScriptを入力してEnterを押すと、このページの上で実行されます。件数の表示（`id="count"` の要素）の `textContent` に、好きな文字列を代入します。
- 画面・Elements パネル・「ページのソースを表示」（タブをリロードして確かめる）が、それぞれどうなったかを書きます。

### 4. Paint flashing で、色の変更と幅の変更を比べる
- DevTools の右上の「︙」→ More tools → Rendering を開き、一覧のいちばん上にある「Paint flashing」にチェックを入れます（日本語表示の場合は「その他のツール」→「レンダリング」）。ブラウザが画面を描き直した範囲が、緑に光るようになります。
- 「1行目の色を変える」と「備品の列の幅を変える」をそれぞれ押し、光った範囲を比べます。

### 5. 1000行の追加を3通りの方法で比べる
`starter/rows.js` の3つの関数を書きます。どれも、`items`（貸出データの配列）の1件につき1行を、`tbody`（表の行を入れる要素）に追加する関数です。
1件のデータから行（`<tr>`）を作る関数 `createRow(item)` は、同じファイルに用意してあります。

| 関数 | 追加のしかた |
|---|---|
| `appendOneByOne` | 1件ずつ、`tbody` の末尾に追加する |
| `appendWithFragment` | 行をすべて作ってから、1回の操作で `tbody` の末尾に追加する |
| `appendWithLayoutRead` | 1件ずつ追加し、追加するたびに `tbody.offsetHeight` を読む |

- 書く前に、遅い順を予想して `notes.md` に書きます。
- 書けたら、ページのボタンを3回ずつ押して、ボタンの下に出る時間（ms）を `notes.md` の表に記録します。ボタンは、押すたびに表を空にしてから1000行を追加します。

## ヒント

<details>
<summary>Hint 1：1でどこを見ればよいかわからない</summary>

`<table>` の直下と、件数の `<p>` のまわりを、1文字ずつ見比べてください。タグの数は同じですか。文字は同じですか。

</details>

<details>
<summary>Hint 2：3で要素をどう取ればよいかわからない</summary>

`document.querySelector()` に、CSSのセレクタと同じ書き方で `id` を渡すと、その要素が返ります。

</details>

<details>
<summary>Hint 3：5で、行をどうやって表に追加するのかわからない</summary>

`親の要素.append(子の要素)` で、親の末尾に子が追加されます。

</details>

<details>
<summary>Hint 4：5の「1回の操作で追加する」方法がわからない</summary>

行をいったん入れておく「まだ画面につながっていない入れ物」を使います。MDNで `DocumentFragment` を調べてください。

</details>

<details>
<summary>Hint 5：5で、値を読むだけの行を書くとlintに怒られる</summary>

読んだ値を使わない式は、先頭に `void` を付けると「わざと捨てている」ことを示せます。

</details>

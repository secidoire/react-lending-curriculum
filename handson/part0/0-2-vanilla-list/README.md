# 0-2 素のJSで貸出一覧

## 状況

総務の田中さんから、貸出一覧のページに依頼が来ました。

> 「いまは一覧を見るだけですけど、ページの上で貸出を追加したり、消したりできるようにしてほしいんです。
> それと、貸出中のものだけに絞って見たいときがあります。」

フレームワークは使いません。ブラウザに最初からあるDOMのAPIだけで作ります。

## 準備

リポジトリのルートで次を実行し、表示されたURLをブラウザで開きます。

```bash
npx vite handson/part0/0-2-vanilla-list/starter
```

- コードを書くファイルは `handson/part0/0-2-vanilla-list/starter/app.js` です。`startApp` 関数の中に書きます（補助の関数も、この中に書いてかまいません。テストは、テスト1件ごとに `startApp` を呼び直します）。
- フォーム（`id="add-form"`）・チェックボックス（`id="lent-only"`）・表の枠は、`starter/index.html` に用意してあります。
- 貸出のデータは `starter/data.js` にあります。状態は `reserved`（予約中）・`lent`（貸出中）・`returned`（返却済）の3つです。
- `solution/` と `bad-examples/` のコードは、勉強会のレビューまで開かないでください。

## やること

1から順に進めます。5は、1〜4が動いてから読んでください。途中でテストを実行すると、まだ作っていない番号のテストは落ちます。それでかまいません。

### 1. 一覧を表示する
- `loans` の1件につき1行を、表（`id="loan-rows"` の `tbody`）に表示します。
- 列は左から「備品」「借りている人」「状態」「メモ」「操作」です。状態は日本語（`STATUS_LABELS`）で出します。
- 「メモ」の列には入力欄（`<input>`）を置きます。入力欄を置くだけでよく、入力された内容を使う処理は書きません。
- 「操作」の列には「削除」ボタンを置きます（動きは3で付けます）。

どの行のものかを区別できるよう、次の属性を付けてください（`要素.setAttribute('aria-label', '…')`）。画面読み上げが使う名前で、テストもこの名前で要素を探します。

| 要素 | 付ける属性 | 例 |
|---|---|---|
| メモの入力欄 | `aria-label="<備品名>のメモ"` | `aria-label="プロジェクターのメモ"` |
| 削除ボタン | `aria-label="<備品名>を削除"` | `aria-label="プロジェクターを削除"` |

### 2. 追加する
- フォームに入力して「追加」を押すと、その貸出が一覧の最後に増えます。
- 追加したら、フォームを最初の状態（入力欄は空、状態は「予約中」）に戻します。
- 追加する貸出の `id` は、ほかと重ならなければ何でもかまいません。

### 3. 削除する
- 「削除」を押すと、その行の貸出が一覧から消えます。

### 4. 貸出中だけに絞り込む
- 「貸出中のみ表示」にチェックが入っている間は、状態が「貸出中」の行だけが見えます。外すと全部に戻ります。
- 見えなくする方法は問いません（隠しても、DOMから取り除いてもかまいません）。

### 5. 仕様追加：件数の表示

1〜4が動いたところで、田中さんから追加の依頼が来ました。

> 「全部で何件あって、そのうち何件が貸出中なのか、いつも見えるようにしてください。絞り込んでいるときも、数は全体の数でお願いします。」

- 表の上に「全3件・貸出中1件」の形で件数を表示します（「・」は全角。0件のときも「貸出中0件」と出します）。表示する要素は `index.html` に足してかまいません。テストは、この文字が画面にあるかどうかで確かめます。
- 件数は、絞り込みの状態にかかわらず、全体を数えます。

### 6. 自分のコードをふり返る
- 5まで終わったら `starter/notes.md` を開き、書いてある問いに答えます。

## 完了条件

- 次のテストが全件パスする。

```bash
npm run test:starter -- handson/part0/0-2-vanilla-list
```

- `notes.md` が埋まっている。

## ヒント

<details>
<summary>Hint 0：ボタンが押されたときなどに、処理を動かす方法がわからない</summary>

`要素.addEventListener('イベント名', (event) => { ... })` で、そのイベントが起きたときに動く関数を登録できます。ボタンが押されたときは `click`、フォームが送信されたときは `submit`、チェックボックスが切り替わったときは `change` です。チェックが入っているかどうかは `チェックボックスの要素.checked` で読めます。

</details>

<details>
<summary>Hint 1：「追加」を押すとページが読み込み直されてしまう</summary>

フォームは、送信されるとページを移動するのが元々の動きです。`submit` イベントで `event.preventDefault()` を呼ぶと、その動きを止められます。

</details>

<details>
<summary>Hint 2：フォームに入力された値の取り方がわからない</summary>

`new FormData(フォームの要素)` を作り、`.get('itemName')` のように `name` 属性の値を渡すと、入力された文字列が返ります。

</details>

<details>
<summary>Hint 3：要素を画面から消す方法がわからない</summary>

`要素.remove()` で、その要素がDOMから取り除かれます。`要素.hidden = true` にすると、DOMに残したまま見えなくなります。

</details>

<details>
<summary>Hint 4：手で試すと動くのに、テストが落ちる</summary>

落ちたテストの名前を読んで、書いてあるとおりの順番に手で操作してみてください。操作のあと、画面のすべての場所を見てください。

</details>

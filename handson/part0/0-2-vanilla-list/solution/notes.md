# 0-2 ふり返りメモ（模範解答：A版の場合）

## 6. 操作ごとに、何を直している？

| 操作 | このときに書き換えているもの（すべて） | 数 |
|---|---|---|
| 追加 | 配列 `loans`、表の行（足す）、行を隠すかどうか（絞り込み中なら隠して足す）、件数の表示 | 4 |
| 削除 | 配列 `loans`、表の行（消す）、件数の表示 | 3 |
| 絞り込みの切り替え | すべての行の、隠す・見せる | 1 |

- 5の件数表示を足すために書き換えた場所：3か所（最初の表示・追加・削除）。
- あとから気づきやすい場所：削除のときの件数と、絞り込み中に追加した行の表示。どちらも、その操作だけを試している間は気づけない。

B版（`solution/b-render/`）では、どの操作もデータ（`loans`・`lentOnly`）だけを直して `render()` を呼ぶ。件数表示を足すために書き換えるのは `render()` の中の1か所。
